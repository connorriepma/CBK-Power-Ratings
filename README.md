# CBK Power Ratings

Power ratings for all 365 Division I men's college basketball teams, 2026-27 season.

## Overview

Each team starts the season with a preseason base rating set during the offseason. As games are played, the model tracks every team's results and updates its rating automatically.

## Status

In development. Preseason ratings are set; in-season updating is being built and tested.
